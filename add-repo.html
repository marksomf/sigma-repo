Add My Repo

Repository URL

https://repo.marksigma.co.uk/

Copy this URL to add to your favorite package manager, or use the quick-add buttons below.

Add to Cydia

  1. Open Cydia
  2. Go to Sources tab
  3. Tap Edit, then Add
  4. Enter the repository URL
  5. Tap Add Source
Quick Add to Cydia

Add to Sileo

  1. Open Sileo
  2. Go to Sources tab
  3. Tap + button
  4. Enter the repository URL
  5. Tap Add Source
Quick Add to Sileo

Add to Zebra

  1. Open Zebra
  2. Go to Sources tab
  3. Tap + button
  4. Enter the repository URL
  5. Tap Add Source
